\section{春训目标}

春训致力于提高会员体能，严明团队纪律，促进会员交流，培养团队责任感，锻炼出能胜任两千公里暑期远征的体魄，磨砺出一支能朝夕共处三十余个日夜的团队。

\section{春训内容}

春训包括为期7周的五四训练、海淀公园绕圈训练、拉练、讲座、体测以及其他相关活动。

\subsection{五四训练}

周一、三、五的五四训练于晚20:35在本部五四体育场跑道西侧会旗下集合签到，20:45签到结束并开始训练。按规定完成训练内容后训练记录一次五四训练考勤。

医学部同学因有晚课无法在集合时间前到达五四操场，需提前与【问道】联系说明情况并在21：00前到达，向队长说明后即可入队。

如遇恶劣天气等特殊情况，文体部会于训练当日20:00前在论坛工作区和大水群通知，改变训练场地或者取消训练。如果训练取消，将于4月26日安排补训，如取消的次数大于一次，只补训一次，多于一次的部分为所有会员计入考勤。

特殊情况的考勤记录和五四训练的纪律要求请见\href{https://chexie.net/bbs/content/index.php?bid=1\&tid=9576\&p=1}{\textit{【文体部】五四训练纪律要求}}。


\subsection{海淀公园绕圈训练}

周二或周四的海淀公园绕圈训练将在训练前2天13:00开放报名，在训练前1天13:00截止。每次训练会有人数限制，报名截止后领队将根据报名顺序拉群，入选后视为报名成功。按规定完成训练内容和要求后根据\href{https://chexie.net/bbs/content/?bid=1&tid=9743&p=1}{\textit{【文体部】24春海淀公园绕圈训练通知}}记录海淀公园绕圈训练考勤。

如遇恶劣天气等特殊情况，文体部会于训练当日20:00前在当次训练群中通知取消训练。如果训练取消，为所有成功报名当次训练（不含报名但未入选的和在通知前已经退出的）的会员计入考勤。

海淀公园绕圈训练的纪律要求请见\href{https://chexie.net/bbs/content/?bid=1&tid=9743&p=1}{\textit{【文体部】24春海淀公园绕圈训练通知}}。

\subsection{拉练}

\subsubsection{单日拉练}

春训前期每周末将开展三次大队单日拉练，每次单日拉练均有对应的前站。每次单日拉练\footnote{不含前站。}记录一次拉练考勤。

\subsubsection{竞技向拉练}

竞技向拉练为面向竞速骑行的拉练，参加记录一次拉练考勤。竞技向拉练由于强度较大，报名资格为满足以下\textbf{所有}条件：
\begin{enumerate}[nosep,left=4em]
    \item 获得一次24春海淀公园绕圈训练考勤（不含恢复性训练）；
    \item 满足以下\textbf{任一}条件：
    \begin{itemize}[nosep,left=1em]
        \item 参加过一次24春训拉练（含前站）；
        \item 参加过一次暑期远征；
        \item 通过一次春训。
    \end{itemize}
\end{enumerate}

\subsubsection{双日拉练}

双日拉练为模拟暑期的高强度小队两日拉练，共设置A、B两组，每人至多参加一组，参加记录两次考勤。双日拉练由于强度较大，报名资格为满足以下\textbf{任一}条件：
\begin{itemize}[nosep,left=4em]
    \item 参加过一次24春训拉练（含前站）；
    \item 参加过一次暑期远征；
    \item 通过一次春训。
\end{itemize}

\subsubsection{穿越拉练}

穿越拉练为面向穿越骑行的拉练，共设置A、B两组，每人至多参加一组，参加记录一次拉练考勤。穿越拉练由于具有一定的危险性，报名资格为满足以下\textbf{任一}条件：
\begin{itemize}[nosep,left=4em]
    \item 参加过两次本年度拉练（含凤凰岭拉练和前站、慕田峪拉练和前站、三日、冬训拉练和前站、半日拉练、黄花城拉练和前站、春训拉练和前站、竞技向拉练、双日拉练）；
    \item 参加过一次暑期远征；
    \item 通过一次春训。
\end{itemize}

在报名成功后，将进行穿越基础技能的教学和考核，通过后方可参与正式拉练。

\subsubsection{注意事项}

如会员因个人原因中途退出拉练，将取消当次拉练考勤。如遇恶劣天气等特殊情况，当次拉练队长将根据实际情况修改拉练终点、推迟或取消拉练。如果拉练取消，为所有成功报名（不含在队长通知前已经退出的）当次拉练的会员计入考勤。


拉练的纪律要求和处罚条例请见当次拉练通知帖、\href{https://chexie.net/bbs/content/?bid=1&tid=9618&p=1}{\textit{北京大学自行车协会出行条例（2023年10月修订）}}和\href{https://chexie.net/bbs/content/?bid=1&tid=9751&p=1}{\textit{北京大学自行车协会纪律处罚条例（2024年2月修订）}}。

\subsection{讲座}


春训期间将开展一次骑行讲座和一次历史讲座。骑行讲座为针对骑行知识所进行的讲座，需要参加往年或本年度的任意一次方可记录\textbf{本次春训骑行讲座考勤}。历史讲座为对协会历史的介绍讲座，必须要参加\textbf{本年度春训历史讲座}方可记录\textbf{本次春训历史讲座考勤}。

如因时间冲突等导致未能参加讲座的，请在讲座后联系讲座主讲人，按主讲人要求完成补考勤任务，完成后视为考勤成功。

\subsection{体测}

春训体测包括跑步体测、平路体测和爬坡体测。

\subsubsection{跑步体测}

跑步体测女生标准为耐力跑$3km$，$16min30s$优秀，$18min$合格。男生标准为耐力跑$4km$，$18min30s$优秀，$20min$合格。

每人有2次跑步体测测试机会，一旦起跑视为使用了1次机会。

\subsubsection{平路体测}

平路体测内容为海淀公园绕圈4圈，共$18.4 km$，只设优秀标准。女生优秀标准暂定为$41 min$（均速$26.9 km/h$），男生优秀标准暂定为$38 min$（均速$29.1 km/h$）。由于平路体测标准为新调整的标准，在5月1日之前，理事会将根据实际情况决定最终的平路体测标准，如果暂定的标准过高，将适当降低标准；不会提高暂定的标准。

每人有2次平路体测测试机会，一旦发车视为使用了1次机会。平路体测将在第1次跑步体测之后开展。

体测车辆要求为：山地车，轮径不限，前后胎均为胎宽不小于1.95 的全齿胎。
必须使用平踏。强烈建议安装后货架。如故意使用窄胎、光头半光头胎、锁踏及
公路车等，均视为体测作弊行为。

\subsubsection{爬坡体测}

爬坡体测为妙峰山牌坊-娘娘庙爬坡。女生标准为$110min$优秀，$130min$合格。男生标准为$90min$优秀，$120min$合格。由于目前体测路段路况不佳，可能会根据体测时的实际路况降低体测标准。

每人有2次爬坡体测测试机会，一旦发车视为使用了1次机会。无特殊情况指定测试时间段（妙峰体测和妙峰补测）外不安排另行补测。

体测车辆要求为：山地车，轮径不限，前后胎均为胎宽不小于1.95的全齿胎。
必须使用平踏。强烈建议安装后货架。如故意使用窄胎、光头半光头胎、锁踏及
公路车等，均视为体测作弊行为。

爬坡体测的爬坡过程中，每人除自己必要补给外，需额外负重3kg，坡底发车员和坡顶计时员届时会检查每个人的负重是否达标。

\section{通过春训的标准}

春训采用累计积分制，通过获得训练和拉练考勤积分，部分考勤可以互抵。通过春训需要满足积分要求，参加完整体测，获得骑行讲座和历史讲座考勤。细则如下。

\subsection{考勤互抵}

部分考勤可以互抵，考勤互抵标准如下：

\begin{itemize}[nosep,left=4em]
    \item 每参加1次前站可抵1次五四训练考勤；
    \item 1次海淀公园绕圈训练考勤可抵1次五四训练考勤，最多4次；
    \item 最多使用前站考勤或海淀公园绕圈训练考勤抵1次后8次五四训练考勤。 
\end{itemize}


\subsection{春训通过标准}

满足以下\textbf{所有}条件即视为通过24春训：
\begin{enumerate}[nosep,left=4em]
    \item 通过过任意1次春训或冬训的会员训练考勤$\ge 9$次，其余会员训练考勤$\ge 11$次。且后8次五四训练考勤
    
    $\ge 4$次\footnote{也即考勤互抵后至少参加11次五四训练，其中后8次五四训练至少参加4次。}；
    \item 拉练考勤$\ge 3$次；
    \item 获得本次春训骑行讲座、历史讲座考勤；
    \item 参加跑步体测且至少完成一次完整的跑步体测\footnote{即女生完整完成3km，男生完整完成4km。}；
    \item 爬坡体测和跑步体测均达到合格标准，且至少一项达到优秀标准。可以使用平路体测的优秀替代跑步体测的合格或优秀。
\end{enumerate}

\section{关于暑期远征}

暑期远征是每年暑假协会组织的官方的骑行活动，一般为期30天，组队长途骑行。暑期队员的选拔方式请见\href{https://chexie.net/bbs/content/?bid=1&tid=9610&p=1}{\textit{北京大学自行车协会暑期队员选拔条例（2012年2月修订）}}。

简要来说，成为暑期预备队员有以下两种方式：
\begin{enumerate}[nosep,left=4em]
    \item 通过本年度春训；
    \item 如果出现重大伤病或变故导致无法通过当次春训的会员，可以申请特批，特批通过后即可获得暑期预备队员资格\footnote{但不视作通过当次春训。}。
\end{enumerate}

另外，\href{https://chexie.net/bbs/content/?bid=1&tid=9610&p=1}{\textit{北京大学自行车协会暑期队员选拔条例（2012年2月修订）}}第3条、\href{https://chexie.net/bbs/content/?bid=1&tid=9751&p=1}{\textit{北京大学自行车协会纪律处罚条例（2024年2月修订）}}第19条规定：“\textit{学年内，自当届执委会成立至当届暑期队员名单公布，因违反《北京大学自行车协会纪律处罚条例》罚跑累计超过11000米者，取消其当届暑期预备队员资格。}”
